# Assets

The supplied PNGs in `branding/` are the source of truth; do not crop, recolor, or regenerate them.

- `av_toolbox_header_dark.png`: dark site headers and Home hero.
- `av_toolbox_header_light.png`: reserved for future branding on light surfaces.
- `av_toolbox_mark.png`: small footer mark.
- `av_toolbox_app_icon.png`: PNG favicon on all pages.

Original inline SVG remains in use for category icons and the projection illustration. No external assets are loaded.

`screenshots/` contains approved real app screenshots used in the Home-page preview section. Their aspect ratios are preserved inside CSS-only phone frames, with descriptive alt text in the page markup.
