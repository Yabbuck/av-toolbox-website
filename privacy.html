2. Privacy in the AV Toolbox app

AV Toolbox is designed primarily for local operation. The current version does not provide user accounts, advertising, analytics or an AV Toolbox cloud backend.

AV Toolbox does not transmit app usage analytics, advertising identifiers or user profiles to the operator of AV Toolbox.

2.1 Local network features

Several AV Toolbox features communicate directly with devices and services selected by the user or discovered on the user's local network.

These features may process technical network information such as IPv4 addresses, host names, ports, service types, DNS-SD information, device information, network interfaces, prefix information and transport type.

This information is processed locally on the user's device for discovery, connection and control functionality. It is not transmitted to an AV Toolbox-operated server.

Network Discovery keeps its discovered-device registry in memory. The discovery registry is not stored persistently.

2.2 Companion Remote

Companion Remote connects directly to the Companion server address selected by the user.

The web content displayed by Companion Remote is provided by that Companion server. AV Toolbox does not operate the selected Companion server and does not route the connection through an AV Toolbox server.

Up to three recently used Companion server addresses may be stored locally on the device so that they can be selected again later. This history can be removed by the user.

Data processing performed independently by a Companion server or another third-party system is subject to the privacy practices of the respective operator.

2.3 Camera Control

Camera Control communicates directly with supported cameras on the network selected by the user.

Control commands and preview data are exchanged directly between the user's device and the camera. Camera preview frames are processed transiently for display and are not uploaded to AV Toolbox or persistently stored by AV Toolbox.

Camera connection state is not stored persistently.

2.4 Local app storage

AV Toolbox stores a limited amount of information locally on the user's device.

This currently includes the selected Light or Dark appearance setting; the selected Metric, Imperial or Custom unit profile; saved per-calculator unit selections for the Custom profile; and up to three recently used Companion server addresses.

The External Display feature can also store a local app-private copy of an image explicitly selected by the user. The app stores technical metadata for that image, including its file name, dimensions and selected scaling mode. The selected image can be removed from within the feature.

Bundled media used by AV Toolbox may also be copied into app-private storage for technical playback purposes.

Locally stored app data is not transferred to AV Toolbox. It normally remains on the device until it is changed or removed by the user, the relevant app data is cleared, or the application is uninstalled, subject to Android's device and backup behaviour.

2.5 Device permissions

The current Android version uses network-related permissions required for local network communication, network-state detection and multicast-based service discovery.

The current version does not request Android permissions for precise or approximate location, the device camera, microphone, contacts or general access to the user's media library.

When the user selects a custom image for External Display, Android's system document picker is used so that the user explicitly chooses the file to which the app receives access.

2.6 Network security

Some professional AV devices and services use protocols such as HTTP that do not provide transport encryption.

AV Toolbox supports such local protocols where required for device compatibility. Users should therefore operate network-control features on trusted local networks and follow the security recommendations of the respective device manufacturer.

AV Toolbox does not use these local connections to transmit data to an AV Toolbox-operated cloud service.

2.7 Third-party services

The current AV Toolbox application does not include advertising or analytics services and does not depend on an AV Toolbox cloud backend.

AV Toolbox can communicate with third-party AV products and services when the user chooses to use the corresponding feature. Those systems are operated independently from AV Toolbox.

Distribution platforms such as Google Play may independently process information relating to downloads, purchases or use of their services under their own privacy policies.

3. AV Toolbox website

The AV Toolbox website consists of static HTML and CSS and is hosted by netcup on infrastructure in Germany within the European Union.

The website code does not include advertising, analytics, tracking scripts, externally hosted fonts or a contact form.

When the website is accessed, technically necessary data may be processed to deliver the requested content and maintain the security and reliability of the hosting service. Depending on the request, this may include the IP address, date and time, requested page or file, request method and status, referrer information if transmitted, browser or user-agent information, operating system and other technical connection data. These data may be stored temporarily in server logs where necessary.

The legal basis is Article 6(1)(f) GDPR. The legitimate interest is the secure, reliable and technically necessary provision of the website.

netcup may process this technical data as the website hosting provider. AV Toolbox does not use server logs for visitor analytics and does not create visitor profiles.

4. Contact by email

Users may contact AV Toolbox by email at support@avtoolbox.app.

When you contact us by email, we process the information contained in the message, your email address and the technical information necessary for delivering and answering the message.

Depending on the content of the request, processing is based on Article 6(1)(b) GDPR where it is necessary for contractual or pre-contractual communication, or Article 6(1)(f) GDPR for general support and communication. Our legitimate interest is answering legitimate enquiries concerning AV Toolbox.

netcup

5. Retention and deletion

Data stored only locally by the AV Toolbox application is not accessible to the operator of AV Toolbox and can be removed through the relevant app feature, by clearing the application's data or by uninstalling the application, depending on the type of data.

Website server logs are retained only for as long as necessary to deliver and secure the website. They are deleted or anonymised when they are no longer required for these purposes, unless longer retention is necessary to investigate a security incident or meet a legal obligation. AV Toolbox does not maintain a separate visitor analytics database.

Email correspondence is retained only for as long as necessary to process the request and, where applicable, for the duration required by statutory retention obligations or the establishment, exercise or defence of legal claims.

6. Recipients and international transfers

AV Toolbox does not sell personal data.

netcup may process technical website access data as the website hosting provider and contact data as the email provider.

Website and email hosting use infrastructure in Germany within the European Union. No transfer of these data outside the European Economic Area is intended.

7. Your rights

Where we process personal data concerning you, you may have the rights provided by the GDPR, including the right of access, rectification, erasure, restriction of processing, objection and, where applicable, data portability.

Where processing is based on consent, consent may be withdrawn at any time with effect for the future.

You also have the right to lodge a complaint with a competent data protection supervisory authority.

Please note that data processed exclusively and locally within the AV Toolbox app is not transmitted to us and therefore cannot be retrieved or deleted by us. Such data can instead be managed on the user's own device.

8. Automated decision-making

AV Toolbox does not use personal data for automated decision-making or profiling that produces legal or similarly significant effects.

9. Changes to this Privacy Policy

This Privacy Policy may be updated if AV Toolbox gains new functionality, adds services, changes hosting providers or otherwise changes its processing of personal data.

The current version will always be published on this page.

2. Datenschutz in der AV-Toolbox-App

AV Toolbox ist überwiegend für den lokalen Betrieb ausgelegt. Die aktuelle Version enthält keine Benutzerkonten, keine Werbung, keine Analysefunktionen und kein von AV Toolbox betriebenes Cloud-Backend.

AV Toolbox übermittelt keine Nutzungsanalysen, Werbe-IDs oder Benutzerprofile an den Betreiber von AV Toolbox.

2.1 Funktionen im lokalen Netzwerk

Mehrere Funktionen von AV Toolbox kommunizieren direkt mit Geräten und Diensten, die vom Nutzer ausgewählt oder im lokalen Netzwerk gefunden werden.

Dabei können technische Netzwerkinformationen wie IPv4-Adressen, Hostnamen, Ports, Diensttypen, DNS-SD-Informationen, Geräteinformationen, Netzwerkschnittstellen, Präfixinformationen und Transportarten verarbeitet werden.

Diese Informationen werden lokal auf dem Gerät des Nutzers verarbeitet, um Geräte zu finden, Verbindungen herzustellen und Geräte zu steuern. Sie werden nicht an einen von AV Toolbox betriebenen Server übertragen.

Die von Network Discovery gefundenen Geräte werden in einem flüchtigen Speicherregister verwaltet. Dieses Discovery-Register wird nicht dauerhaft gespeichert.

2.2 Companion Remote

Companion Remote verbindet sich direkt mit der vom Nutzer ausgewählten Companion-Serveradresse.

Die in Companion Remote dargestellten Webinhalte werden unmittelbar vom jeweiligen Companion-Server bereitgestellt. AV Toolbox betreibt diesen Server nicht und leitet die Verbindung nicht über einen AV-Toolbox-Server.

Bis zu drei zuletzt verwendete Companion-Serveradressen können lokal auf dem Gerät gespeichert werden, damit sie später erneut ausgewählt werden können. Der Nutzer kann diesen Verlauf entfernen.

Eine eigenständige Datenverarbeitung durch einen Companion-Server oder ein anderes Drittsystem richtet sich nach den Datenschutzbestimmungen des jeweiligen Betreibers.

2.3 Camera Control

Camera Control kommuniziert direkt mit unterstützten Kameras im vom Nutzer ausgewählten Netzwerk.

Steuerbefehle und Vorschaudaten werden direkt zwischen dem Gerät des Nutzers und der Kamera übertragen. Kameravorschaubilder werden lediglich vorübergehend zur Darstellung verarbeitet und weder an AV Toolbox hochgeladen noch durch AV Toolbox dauerhaft gespeichert.

Der Verbindungsstatus einer Kamera wird nicht dauerhaft gespeichert.

2.4 Lokale Speicherung in der App

AV Toolbox speichert nur eine begrenzte Menge an Informationen lokal auf dem Gerät des Nutzers.

Dazu gehören aktuell die ausgewählte Darstellung im Light- oder Dark-Mode, das ausgewählte Einheitenprofil Metric, Imperial oder Custom, gespeicherte Einheiten je Rechner für das Custom-Profil sowie bis zu drei zuletzt verwendete Companion-Serveradressen.

Die Funktion External Display kann außerdem eine lokale, ausschließlich der App zugängliche Kopie eines vom Nutzer ausdrücklich ausgewählten Bildes speichern. Zusätzlich werden technische Metadaten wie Dateiname, Abmessungen und gewählter Skalierungsmodus gespeichert. Das ausgewählte Bild kann innerhalb der Funktion wieder entfernt werden.

Mit der App ausgelieferte Mediendateien können für die technische Wiedergabe ebenfalls in den privaten App-Speicher kopiert werden.

Lokal gespeicherte App-Daten werden nicht an AV Toolbox übertragen. Sie verbleiben grundsätzlich auf dem Gerät, bis sie vom Nutzer geändert oder gelöscht werden, die App-Daten gelöscht werden oder die Anwendung deinstalliert wird. Abweichendes Verhalten des Android-Betriebssystems oder von Geräte- beziehungsweise Backup-Funktionen bleibt hiervon unberührt.

2.5 Geräteberechtigungen

Die aktuelle Android-Version verwendet netzwerkbezogene Berechtigungen, die für die Kommunikation im lokalen Netzwerk, die Erkennung des Netzwerkstatus und die multicastbasierte Dienstsuche erforderlich sind.

Die aktuelle Version verlangt keine Android-Berechtigungen für den ungefähren oder genauen Standort, die Gerätekamera, das Mikrofon, Kontakte oder einen allgemeinen Zugriff auf die Medienbibliothek.

Wenn der Nutzer ein eigenes Bild für External Display auswählt, wird der System-Dateiauswahldialog von Android verwendet. Dadurch bestimmt der Nutzer ausdrücklich, auf welche Datei die App zugreifen darf.

2.6 Netzwerksicherheit

Einige professionelle AV-Geräte und Dienste verwenden Protokolle wie HTTP, die keine Transportverschlüsselung bereitstellen.

AV Toolbox unterstützt solche lokalen Protokolle, soweit dies für die Kompatibilität mit den jeweiligen Geräten erforderlich ist. Netzwerksteuerungsfunktionen sollten deshalb ausschließlich in vertrauenswürdigen lokalen Netzwerken verwendet werden. Zusätzlich sollten die Sicherheitsempfehlungen des jeweiligen Geräteherstellers beachtet werden.

AV Toolbox nutzt diese lokalen Verbindungen nicht zur Übertragung von Daten an einen von AV Toolbox betriebenen Cloud-Dienst.

2.7 Dienste Dritter

Die aktuelle AV-Toolbox-App enthält keine Werbe- oder Analysedienste und verwendet kein von AV Toolbox betriebenes Cloud-Backend.

AV Toolbox kann mit AV-Produkten und Diensten anderer Anbieter kommunizieren, wenn der Nutzer die entsprechende Funktion verwendet. Diese Systeme werden unabhängig von AV Toolbox betrieben.

Vertriebsplattformen wie Google Play können unabhängig davon Informationen im Zusammenhang mit Downloads, Käufen oder der Nutzung ihrer Dienste entsprechend ihren eigenen Datenschutzbestimmungen verarbeiten.
